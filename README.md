# GlobeSwitch

Мгновенное переключение раскладки клавиатуры по клавише 🌐 (Fn) на macOS 13+.
Замена системного действия «Нажатие клавиши 🌐 → Сменить источник ввода», которое
срабатывает с задержкой, иногда не срабатывает и показывает медленный индикатор.

## Как это работает

- Приложение живёт в строке меню (значок 🌐), окон нет.
- Через `CGEventTap` на уровне HID оно видит нажатие и отпускание Fn. **Чистое нажатие**
  (между нажатием и отпусканием не нажато ничего другого: клавиши, модификаторы, мышь,
  клавиши яркости/громкости) = переключение на следующую включённую раскладку через
  `TISSelectInputSource` — порядок раскладок тот же, что в системном меню ввода.
- Комбинации `Fn+стрелки`, `Fn+F-клавиши`, `Fn+Delete`, `Fn+E` (эмодзи) и т. п. не затрагиваются.
- По умолчанию событие Fn «съедается» и не доходит до системы, чтобы системное действие 🌐
  не срабатывало вторым. При первом запуске приложение дополнительно предлагает выключить
  системное действие (`com.apple.HIToolbox AppleFnUsageType = 0`, «Ничего не делать»).
- После переключения на 0,6 с показывается индикатор `RU` / `EN` (отключается в меню).
- Переключение происходит **при отпускании** Fn — так же, как у системы: раньше нельзя
  понять, одиночное это нажатие или начало комбинации `Fn+клавиша`.

## Сборка и установка

Нужны Command Line Tools (`xcode-select --install`), Xcode не требуется.

```bash
./build.sh --install
```

Скрипт собирает `build/GlobeSwitch.app` (SwiftPM, release, ad-hoc подпись), копирует его в
`/Applications` (или `~/Applications`, если первый недоступен) и запускает. Без `--install`
только собирает.

## Разрешения

Нужен **Универсальный доступ** (Настройки → Конфиденциальность и безопасность →
Универсальный доступ): без него event tap создать нельзя. При первом запуске macOS сама
покажет запрос; пока разрешения нет, значок в строке меню серый, а в меню есть пункт для
перехода в настройки.

Подпись ad-hoc меняется с каждой сборкой, поэтому после `./build.sh --install` новой версии
разрешение нужно выдать заново. Скрипт сам сбрасывает устаревшую запись (`tccutil reset
Accessibility`), и приложение при запуске снова покажет системный запрос. Если разрешение выдано,
а значок остаётся серым, приложение через ~10 с один раз перезапустит себя — macOS иногда применяет
новое разрешение только к свежему процессу.

## Меню

- список включённых раскладок (галочка — текущая; клик — выбрать её вручную)
- **Показывать индикатор раскладки** — RU/EN на 0,6 с после переключения
- **Перехватывать 🌐 у системы** — не отдавать событие Fn системе. Выключите, если какая-то
  программа использует Fn как отдельную кнопку (например, рация в Discord)
- **Запускать при входе в систему** — через `SMAppService` (macOS 13+)
- **Системное действие клавиши 🌐…** — открывает Настройки → Клавиатура
- время последнего переключения в миллисекундах (для контроля)

## Диагностика из терминала

```bash
/Applications/GlobeSwitch.app/Contents/MacOS/GlobeSwitch --list   # раскладки, * — текущая
/Applications/GlobeSwitch.app/Contents/MacOS/GlobeSwitch --next   # переключить и показать время
```

## Ограничения

- В полях ввода пароля (Secure Input) macOS не отдаёт события клавиатуры сторонним
  программам — там переключение через GlobeSwitch может не сработать.
- Сторонние клавиатуры без клавиши Fn/🌐 приложение не затрагивает.

## Структура

```
Package.swift                      SwiftPM, один executable target
Sources/GlobeSwitch/main.swift     точка входа; --list / --next уходят в CLI
Sources/GlobeSwitch/FnTap.swift    event tap: чистое нажатие Fn, комбинации, swallow
Sources/GlobeSwitch/InputSources.swift  список раскладок (TIS), порядок как в системе, selectNext
Sources/GlobeSwitch/AppDelegate.swift   строка меню, разрешение, предложение выключить системное действие
Sources/GlobeSwitch/HUD.swift      индикатор RU/EN
Sources/GlobeSwitch/NativeFnSetting.swift  чтение/запись AppleFnUsageType
Sources/GlobeSwitch/Settings.swift  UserDefaults
Sources/GlobeSwitch/CLI.swift      диагностика из терминала
Tools/make_icon.swift              генерирует иконку (SF Symbol «globe» на синем)
Resources/Info.plist               LSUIElement = true (без иконки в Dock)
build.sh                           сборка, упаковка в .app, подпись, --install
```
